# 💻 Portfólio — André Oliveira Cornely

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades, projetos e conhecimentos na área de desenvolvimento web.

O projeto possui uma interface inspirada em **editores de código e terminais**, com navegação por abas e uma identidade visual voltada para tecnologia e desenvolvimento.

## 🚀 Sobre o projeto

Este portfólio foi desenvolvido para servir como uma apresentação profissional dos meus conhecimentos e projetos.

A página conta com diferentes seções para organizar as informações:

* **About** — apresentação pessoal e área de atuação
* **Skills** — tecnologias e habilidades
* **Projects** — projetos desenvolvidos
* **Resume** — formação acadêmica, experiência e currículo em PDF

Também possui links para minhas redes profissionais e plataformas de desenvolvimento.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Responsive Design
* SVG
* Google Fonts
* Devicon

## ✨ Funcionalidades

* Navegação entre seções sem recarregar a página
* Sistema de abas interativo
* Filtro de projetos por categoria
* Menu responsivo para dispositivos móveis
* Animações e transições
* Links para GitHub, LinkedIn, LeetCode e Instagram
* Visualização e download do currículo em PDF
* Atualização automática do ano no rodapé
* Layout responsivo para diferentes tamanhos de tela

## 📱 Responsividade

O projeto foi desenvolvido pensando em diferentes tamanhos de tela, adaptando o layout para **desktop, tablet e dispositivos móveis**.

Em telas menores, a barra lateral é transformada em um menu que pode ser aberto e fechado pelo usuário.

## 🎨 Interface

A identidade visual utiliza uma combinação de:

* Tema escuro
* Elementos inspirados em terminal
* Tipografia `JetBrains Mono`
* Tipografia `Inter`
* Detalhes em vermelho
* Cards e componentes com bordas e efeitos de interação
